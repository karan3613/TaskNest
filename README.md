# 🪶 TaskNest — Your Smart Notes & To-Do Manager

### A clean, fast, and offline-first Notes & Tasks app built with **Kotlin**, **Jetpack Compose**, and **Room Database**.

## 🚀 Overview

**TaskNest** helps you capture ideas, plan tasks, and stay productive — all in one elegant interface.  
Built entirely with **Jetpack Compose**, it showcases how to create a full-featured CRUD (Create, Read, Update, Delete) application using **Room** for persistent local storage.

## ✨ Features

✅ Add and save new tasks or notes instantly  
📝 Edit or update existing tasks easily  
❌ Delete notes you no longer need  
📋 View your notes and to-do list in a sleek Compose UI  
💾 100% **Offline Support** with Room Database  
🎨 Modern **Material 3 UI** built with Jetpack Compose  


## 🧰 Tech Stack

| Layer | Technology |
|--------|-------------|
| UI | **Jetpack Compose** |
| Local Storage | **Room Database (SQLite)** |
| Architecture | **MVVM (Model–View–ViewModel)** |
| Language | **Kotlin** |
| Dependency Injection | **Hilt (optional)** |
| Build Tool | **Gradle (KTS)** |

## ⚙️ Core Features in Action

1️⃣ **Add Tasks or Notes**  
Quickly create new tasks with titles and descriptions.  

2️⃣ **Edit Notes**  
Tap on any existing note to update its content.  

3️⃣ **Delete Tasks**  
Remove tasks that are no longer needed with a single tap.  

4️⃣ **View List**  
See all your saved tasks displayed beautifully in a `LazyColumn`.  



## 🧠 Learning Highlights

This project demonstrates:
- How to build a full **CRUD app** using **Jetpack Compose + Room**
- Proper **MVVM architecture** for clean state management
- Handling **UI updates automatically** with Compose state
- Using **Coroutines** for database operations off the main thread
